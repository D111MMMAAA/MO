# Линейная регрессия: прогноз медицинских расходов (Medical Cost Personal Datasets)

Лабораторная работа по линейной регрессии на датасете
[Medical Cost Personal Datasets](https://www.kaggle.com/datasets/mirichoi0218/insurance) (Kaggle).

**Цель:** спрогнозировать медицинские расходы (`charges`) по возрасту, полу, ИМТ, числу детей, статусу курения и региону.

## Что сделано

1. Первичный анализ и визуализация распределений признаков и целевой переменной
2. Предобработка: удаление дубликатов и пропусков, кодирование категориальных признаков
3. Корреляционная матрица и расчёт VIF (проверка мультиколлинеарности)
4. Линейная, Lasso и Ridge регрессии, разбиение 80/20, 5-блочная кросс-валидация, метрики RMSE, R², MAPE
5. Стандартизация и метод главных компонент (PCA), scree plot
6. Повтор регрессий на главных компонентах и сравнение метрик

## Основные результаты

- Мультиколлинеарность отсутствует (все VIF < 2).
- Лучшая модель на исходных признаках — линейная регрессия: RMSE ≈ 5956, R² ≈ 0.807, MAPE ≈ 41.4%.
- Главный фактор расходов — `smoker`.
- PCA не дал существенного снижения размерности (7 компонент из 8 для 90% дисперсии) и не улучшил качество моделей.
